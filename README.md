# 重力小球 · 1分钟减价挑战

手机端优先的 Three.js 重力感应小游戏。玩家填写手机号后，在 60 秒内倾斜手机躲避坑洞、收集一元硬币；每枚硬币对应 1 元减价，结束后生成只显示脱敏手机号的截图凭证。

正式入口：<https://haoduoo.com/ballgame/>

## 本地预览

```bash
python3 -m http.server 8765
```

打开 <http://127.0.0.1:8765/>。

## 服务端记录

完整手机号和当局结果保存在阿里云服务器的私有 SQLite 数据库中，游戏画面和结算凭证只显示脱敏手机号。服务器按北京时间执行“每个手机号每天最多一次”，数据库和会话均不位于网站静态目录。
